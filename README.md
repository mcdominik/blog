# Dominik Builds

[Dominik Builds](https://www.dominikbuilds.com) is my personal blog about programming, electronics, and robotics. I share practical tutorials and hands-on projects for developers and makers.

The site is built with [Astro](https://astro.build/) and [Svelte](https://svelte.dev/), with a focus on performance, accessibility, and SEO.
